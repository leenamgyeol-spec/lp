# lp

앨범을 폴더에 넣으면 앨범마다 다른 LP가 만들어지고, 턴테이블에 올려 들을 수 있는 웹 페이지예요.

**사이트:** https://charaing.github.io/lp/

## 앨범 넣기

`albums/` 아래에 앨범마다 폴더를 하나 만들고 표지와 노래를 넣은 뒤 `main`에 푸시하세요. 몇 분 뒤 사이트에 나타나요.

```
albums/
└─ 내 앨범/
   ├─ cover.jpg          표지 (jpg, png, webp — 없어도 됨)
   ├─ 01 첫 곡.mp3       노래 (mp3, m4a, ogg, wav, flac)
   ├─ 02 두 번째 곡.mp3
   └─ album.json         선택 사항
```

- 트랙 순서는 파일 이름 순서예요(`2`가 `10`보다 먼저). 앞의 번호와 확장자를 뺀 나머지가 곡 제목이 돼요.
- 노래 파일이 없는 폴더는 건너뛰어요.
- LP 색과 무늬는 표지에서 자동으로 정해져요. 같은 앨범은 항상 같은 LP가 나와요.

### album.json (선택)

제목·아티스트와 LP 모양을 정해요. 직접 쓰기보다 사이트의 **꾸미기 → 모두에게 적용**으로 코드를 복사해 붙여넣는 게 편해요.

```json
{
  "title": "앨범 제목",
  "artist": "아티스트",
  "year": 2026,
  "vinyl": { "style": "marble", "color": "#c0392b", "accent": "#f5d76e", "shape": "round", "size": 12 },
  "label": { "mode": "cover", "size": 0.36, "color": "#111111", "text": "#ffffff", "showTitle": false, "ring": true },
  "finish": { "grooves": 0.5, "gloss": 0.6 },
  "deck": { "body": "auto", "arm": "silver" },
  "rpm": 33
}
```

| 항목 | 값 |
|---|---|
| `title` | 없으면 폴더 이름 |
| `vinyl.style` | `black` 검정(기본), `solid` 단색, `translucent` 반투명, `marble` 마블, `splatter` 스플래터, `gradient` 그라데이션, `half` 반반, `glitter` 글리터, `picture` 픽처 디스크 |
| `vinyl.color`, `vinyl.accent` | 바이닐 색과 무늬 보조색 (`#rrggbb`) |
| `vinyl.shape` | `round` 원, `heart` 하트, `star` 별, `hexagon` 육각형, `flower` 꽃 |
| `vinyl.size` | `7`, `10`, `12` (인치) |
| `label.mode` | `cover` 앨범 표지, `color` 단색, `text` 글자 |
| `label.size` | 0.25–0.45 (모양이 뾰족하거나 작으면 자동으로 줄어요) |
| `label.color`, `label.text` | 라벨 바탕색, 글자색 |
| `label.showTitle`, `label.ring` | 제목·아티스트 표시, 라벨 테두리 (`true`/`false`) |
| `finish.grooves`, `finish.gloss` | 홈 선명도, 광택 (0–1) |
| `deck.body` | 턴테이블 몸체 색: `auto`(표지 색) 또는 `#rrggbb` |
| `deck.arm` | 톤암: `silver`, `gold`, `black` |
| `rpm` | 33 또는 45. 처음 선택될 회전 속도 |

## 조작

- 첫 화면에서 재킷을 좌우로 넘기고(손가락으로 끌기·휠·`←` `→`), 가운데 재킷을 누르면 LP를 꺼내 턴테이블에 올려요. 주소 끝에 `#앨범폴더이름`을 붙이면 그 앨범 턴테이블이 바로 열려요.
- 턴테이블 색은 앨범 표지에서 자동으로 정해지고, LP는 기본적으로 검은 바이닐에 표지가 라벨로 들어가요. `album.json`에 `vinyl`을 적은 앨범만 그 색·무늬로 나와요.
- 재생 버튼은 없어요. **톤암을 레코드 위에 올리면** 턴테이블이 돌면서 바늘이 놓인 자리부터 재생돼요. 곡 중간에 놓으면 중간부터 들을 수 있어요. 바깥쪽이 1번 곡이고, 라벨 가까이 안쪽 끝(런아웃)에 놓으면 소리가 나지 않아요. 키보드 Space로도 재생/정지할 수 있어요.
- **톤암을 받침대로 돌려놓으면** 멈추고, ⏮ ⏭ 버튼으로 이전/다음 곡. 재생 중에 왼쪽 위 **레코드 고르기**로 돌아가도 노래는 계속 나오고, 그 앨범 재킷에서 LP가 반쯤 나와 돌아가요. 재킷을 누르면 턴테이블로 돌아와요. 멈춘 상태로 돌아가면 LP가 재킷에 들어가요.
- **레코드를 손가락·마우스로 잡고 돌리면** 실제 LP처럼 소리가 따라와요. 앞으로 빠르게 돌리면 빨리감기, 천천히 돌리면 느리게, 뒤로 돌리면 거꾸로(스크래치). 돌리는 동안 바늘이 홈을 긁는 치직거리는 잡음도 같이 나요. 놓으면 그 자리부터 이어서 재생돼요. 곡마다 처음 잡을 때 1초쯤 준비 시간이 있어요.
- 키보드: `Space` 재생/정지, `←` `→` 이전/다음 곡.
- 턴테이블 화면 오른쪽 아래 **꾸미기**로 LP 무늬·색·모양·크기·라벨·질감, 턴테이블 색, 톤암 색을 바꿀 수 있어요. 바꾼 모양은 이 브라우저에 앨범마다 저장되고, **되돌리기**로 원래대로, **모두에게 적용**으로 album.json 코드를 복사해요.
- 아이폰: Safari 공유 버튼 → **홈 화면에 추가**로 앱처럼 쓸 수 있어요. 재생 중에는 잠금 화면과 다이내믹 아일랜드에 곡 제목·아티스트와 꾸민 LP 그림이 뜨고, 거기서 재생/정지와 이전/다음 곡도 돼요.

## 데모 앨범

예시 앨범이 필요하면 `npm run demo`를 실행하세요. 직접 합성한 소리와 그림으로 `albums/demo-*` 앨범 세 개를 만들어요.

## 내 컴퓨터에서 보기

Node 22 이상이 필요해요.

```bash
npm run build
```

```bash
npm run serve
```

그다음 http://localhost:8080 을 여세요. 테스트는 `npm test`로 실행해요.
